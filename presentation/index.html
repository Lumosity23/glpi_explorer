API GLPI
Cache Intelligent Local
Interface CLI

GLPI Explorer résout le problème de lenteur des requêtes dans les grands inventaires GLPI en introduisant un cache intelligent local qui agit comme un double numérique de votre infrastructure. Cette approche transforme GLPI d'un simple outil d'inventaire statique en une plateforme dynamique pour explorer et comprendre votre infrastructure réseau.

Le Défi Actuel : Le Passage à l'Échelle

Sur des parcs de grande taille (+10 000 objets), le chargement initial du cache est trop long, ce qui impacte l'ergonomie. Notre priorité est l'optimisation.

Plan d'Optimisation

  • Chargement "Paresseux" (Lazy Loading)
  • Optimisation des Requêtes API (parallélisation)
  • Format de Cache Binaire plus performant
Objectif : Un temps de démarrage inférieur à 30 secondes, même sur l'infrastructure complète.

Le Futur : Un Écosystème Complet de Gestion Réseau

Feuille de Route des Fonctionnalités

  • Audit & Conformité (`checkup`) : Auditer le parc pour détecter les anomalies (câbles orphelins, erreurs de nomenclature, etc.).
  • Mode "Constructeur" (`create`, `connect`) : Créer et câbler de nouveaux équipements directement depuis le CLI.
  • Éditeur Visuel (`network-map`) : Une interface web pour visualiser et éditer la topologie en glisser-déposer.
